# CAS-V comparison board

Demo of **CAS-V (conflict-aware semantic verification)** for image-to-audio generation.

For each uploaded image, CLIP recognises the scene (Places365) and objects (ImageNet), 20 candidate sound
captions are retrieved from the AudioCaps train split, and captions that conflict with the image are rejected:
a sound tied to the wrong setting (indoor vs outdoor), or a sound source that is not visible. The board compares

- **Existing research (without CAS-V):** AudioLDM prompted with the top-1 retrieved caption, unverified
- **Ours (CAS-V):** the same generator and seed prompted with the verified caption, with its verified concepts
  and sound type
- **Target sound:** a real recording, if you upload one with the same file name as its image

and is laid out like the figures in the paper. A downloadable zip holds the board, a caption file with the
provenance of every panel, the generated clips and the per-image records.

## What this demo is and is not

It shows what the method does on images you choose. Hand-picked images make the board an illustration, not
a result. On 400 AudioCaps test clips, CAS-V showed no measurable CLAP gain over the baseline (+0.003,
95% CI [-0.012, +0.019]); a blind listening test is in preparation. Full protocol and results:
https://github.com/Patiencewantae123/CAS-CLAP-2

## Running

The Space runs on ZeroGPU: recognition and verification on CPU, AudioLDM on a shared GPU charged to the
visitor's daily ZeroGPU quota. Uploads and results are kept only in the Space's temporary storage. Locally:
`pip install -r requirements.txt gradio==6.31.0` and `python app_gradio.py` (CPU, about 1-2 min per clip).

This folder is generated by `py -m scripts.build_space` in the repository; edit the files there, not here.
